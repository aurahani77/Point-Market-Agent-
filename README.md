# 📦 Point Market - نظام إدارة المخزون المتكامل

نظام احترافي متكامل لإدارة المخزون والمبيعات والفروع بـ HTML/CSS/JavaScript فقط بدون backend.

## ✨ المميزات الرئيسية

### 🔐 نظام المصادقة
- تسجيل دخول محلي آمن
- ثلاث مستويات صلاحيات: مسؤول، مدير، موظف
- إدارة الجلسات
- سجل النشاط

### 📦 إدارة المنتجات
- CRUD كامل للمنتجات (30 منتج جاهز)
- تصنيفات المنتجات
- حساب الهوامش والأرباح

### 📋 إدارة المخزون
- تتبع حي للمخزون (1,050+ سجل)
- تنبيهات تلقائية
- سجل التحركات
- البحث والتصفية المتقدم

### 🏢 إدارة الفروع
- 35 فرع في جميع أنحاء المملكة
- خريطة تفاعلية (Leaflet.js)
- تحليل الأداء

### 💰 نظام الفواتير والمبيعات
- إنشاء فواتير فورية
- تتبع المبيعات
- حساب الضريبة والخصم
- طباعة/تصدير

### 📊 التقارير والتحليلات
- رسوم بيانية تفاعلية
- تقارير شاملة
- توقعات الطلب

### 🤖 الوكيل الذكي
- توصيات ذكية
- تحليل الأداء التلقائي
- مؤشر صحة النظام

### 🎨 التصميم
- Design متجاوب (Desktop/Tablet/Mobile)
- Dark Mode / Light Mode
- سرعة تحميل عالية

## 🚀 البدء السريع

### تشغيل التطبيق
```bash
# استخدم أي خادم محلي
python -m http.server 8000
# أو
npx http-server

# ثم افتح http://localhost:8000
```

## 🔐 بيانات الدخول
- **admin / 123456** (مسؤول)
- **manager / 123456** (مدير)
- **staff / 123456** (موظف)

## 📂 البنية
- **index.html**: الصفحة الرئيسية
- **css/**: ملفات التنسيق
- **js/**: منطق التطبيق (db, auth, products, inventory, branches, sales, reports, ai-agent, app)

## 🛠️ التكنولوجيا
- HTML5 + CSS3 + JavaScript (Vanilla)
- IndexedDB (قاعدة بيانات محلية)
- Chart.js (رسوم بيانية)
- Leaflet.js (خريطة تفاعلية)
- jsPDF & SheetJS (تصدير)
